## 🌟 What's New in v1.0.3

### 1. ✨ Aceternity / Shadcn Interactive Drag & Drop Component
- Integrated Framer Motion spring physics, grid pattern background, and file inspection state into the Drag & Drop component (`components/ui/file-upload.tsx`).
- Drop any local Git repository folder onto the application window to automatically inspect identity, remote origin URL, and hook status.

### 2. 🔍 Real-Time Repository Search Bar
- Added search input bar to filter local repository cards in real-time by folder name, path, author name, or email.

### 3. ⚡ 1-Click Identity Switcher, Custom Edit, & Unset Controls
- 1-Click Account Switcher dropdown to assign any registered profile.
- Unset identity button to clear local `user.name` & `user.email` entries.
- Edit modal for manual `user.name` & `user.email` overrides.

### 4. 🎨 UI & Layout Streamlining
- Streamlined repository manager layout into a clean, modern Apple Pro UI without duplicate headers or text overlap.
